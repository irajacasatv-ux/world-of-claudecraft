2. **P3, high confidence: the forbidden-material controls do not cover the requested protected set.** `scripts/freeholds/crafted_economy_probe.ts:132` uses `quickening_charm`, while the pacing catalyst is `quickening_catalyst` (`src/sim/content/recipes.ts:2230`). The positive allowlist currently excludes all of these, so no forbidden input was found in the generated rows. Nevertheless, seven controls are not proof of the complete-set claim: add the actual catalyst and each excluded family, exercising the same checker. The production provisioner firewall tests remain a separate implementation obligation.
