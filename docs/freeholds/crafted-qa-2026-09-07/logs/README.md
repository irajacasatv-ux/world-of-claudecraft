# Executed command logs

Readable copies of actual coordinator and assigned worker output. ANSI display escapes, trailing display whitespace and extra final blank lines were removed; all content tokens, test assertions and outcomes were preserved. Filenames containing before, mutant, merge-pins, integration-final, fixes-scoped, or gate-attempt1 can intentionally record failures. Read ../validation.md and ../findings.md for the repair and accepted later run.

Original reviewer reports retain historical /tmp paths. A path /tmp/freeholds-crafted-qa-NAME.log corresponds to freeholds-crafted-qa-NAME.txt here when archived. The first full-gate /tmp/freeholds-crafted-qa-gate-final.log is archived as freeholds-crafted-qa-gate-attempt1.txt; its misleading temporary filename is not a final PASS claim. The separate error-only Biome log preserves the two formatting diagnostics.

Untracked .log working copies are ignored and are not the portable evidence. The committed .txt files are the reviewable records.
